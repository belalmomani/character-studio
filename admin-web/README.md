# لوحة إدارة الويب
**منفَّذ:** تسجيل دخول (Supabase Auth) مع تحقق من دور administrator من الخادم · لوحة معلومات بأرقام حقيقية ·
الفئات (مع زر إضافة الفئات الأساسية الـ 26) · التراخيص واعتمادها/رفضها · **إضافة الأصول من الهاتف** (رفع PNG/WebP إلى Cloudinary،
نقاط التثبيت بلمس الصورة، تسعير مجاني/مدفوع، نسخة جديدة، نشر/إخفاء/أرشفة) · إعدادات الإعلانات المكافأة · سجل التدقيق.
**تقطيع الصور:** من تبويب «الأصول» ← «تقطيع صورة إلى أجزاء». ثلاث طرق: شبكة (صفوف × أعمدة مع هامش ومسافة)،
كشف تلقائي للأجزاء المنفصلة بالشفافية مع دمج الأجزاء المتقاربة، أو رسم يدوي بالإصبع. الخطوة 1: حذف الخلايا الشفافة الفارغة تلقائيًا (بعتبة وأقل عدد بكسلات قابلة للضبط) ثم الخطوة 2: قص الحواف الشفافة، وحشوة،
مراجعة كل جزء وتسميته وحذفه، ثم رفع المحدد كأصول مسودة بالبيانات نفسها (فئة/نمط/زاوية/تسعير/ترخيص). الحد: 4096×4096.
**غير منفَّذ بعد:** الميزات والأسعار والاشتراكات والمدفوعات والتحويل البنكي وإدارة المستخدمين والمصادقة الثنائية وقواعد التوافق بين الأصول.

## اختبار خوارزميات التقطيع
`node admin-web/tests/slice-core.test.js` (16 اختبارًا، ينفَّذ أيضًا في GitHub Actions).

## الإعداد (مرة واحدة، من متصفح الهاتف)
1. Supabase → SQL Editor: شغّل الملف المجمَّع (0002-0005) ثم `0006_admin_assets.sql`.
2. Supabase → Authentication → Users → Add user: أنشئ حسابك (bilalalmomani90@gmail.com) بكلمة مرور قوية وأكّد البريد، ثم شغّل `seed_admin.sql`.
3. Cloudinary: أنشئ حسابًا مجانيًا، وانسخ Cloud name وAPI Key وAPI Secret من Dashboard (السر لا يُرسل لأحد ولا يوضع في config.js).
4. Supabase → Edge Functions → Deploy a new function باسم `sign-upload` (Via Editor) والصق محتوى `backend/supabase/functions/sign-upload/index.ts`.
   ثم Edge Functions → Secrets وأضف: `CLOUDINARY_CLOUD_NAME` و`CLOUDINARY_API_KEY` و`CLOUDINARY_API_SECRET`.
5. عدّل `admin-web/config.js`: SUPABASE_URL والمفتاح العام anon/publishable واسم سحابة Cloudinary. لا تضع service_role.
6. استضف مجلد admin-web على Cloudflare Pages أو Netlify (رفع ملفات ثابتة) وافتح الرابط من الهاتف.

## ترتيب العمل لنشر أول أصل
الفئات (إضافة الأساسية) ← ترخيص (مع علامة «تجاري مسموح») ثم «اعتماد» ← الأصول ← إضافة أصل ← «نشر».
الخادم يرفض نشر أي أصل بلا نسخة وبلا ترخيص معتمد للاستخدام التجاري، ويُخفي الأصول تلقائيًا إن رُفض ترخيصها.

## ملاحظات
- الأمان الفعلي في الخادم (RLS ودالة is_admin وفحص الدالة sign-upload للدور)؛ الواجهة لا تمنح صلاحية.
- رابط الصورة على Cloudinary عام: الأصول «المدفوعة» غير محمية من التنزيل بمعرفة الرابط. الحماية الحقيقية تحتاج تسليمًا موقّعًا لاحقًا.
- يجب أن تملك حقوق كل صورة ترفعها وتسجّل مصدرها وترخيصها بصدق.
