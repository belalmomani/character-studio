# مرشحو إنشاء النموذج من صورة (تقييم أولي)

مأخوذ من وثائق وصفحات بحث بتاريخ 2026-10-19. الأسعار والحدود تتغير، وتُراجَع من الصفحات الرسمية قبل أي اعتماد.

| المزود | ما تحقق منه | غير متحقق منه |
|---|---|---|
| Meshy API | تسعير بالرصيد ودفع مسبق (docs.meshy.ai/api/pricing)؛ تجهيز آلي للهيكل وحركات | تعارض بين صفحتين حول تكلفة التجهيز/الحركة؛ شروط الاستخدام التجاري لمخرجات الخطة المجانية؛ سياسة الاحتفاظ بالصور؛ هل API يتطلب خطة مدفوعة |
| Tripo | تصدير GLB وFBX وتجهيز آلي للشخصيات البشرية (مصادر ثانوية) | الأسعار الرسمية (platform.tripo3d.ai/docs/billing)، سياسة الاحتفاظ، الترخيص |
| TRELLIS.2 (مفتوح المصدر) | ترخيص MIT يسمح بالاستخدام التجاري | يحتاج خادم GPU خاصًا؛ لا تجهيز هيكل عظمي؛ جودة الأجسام البشرية |
| Hunyuan3D-2.1 | ترخيص مجتمعي بشروط وقيود جغرافية | مراجعة الترخيص قبل الاستخدام التجاري |
| Stable Fast 3D | ترخيص مجتمعي يتطلب ترخيصًا مؤسسيًا فوق حد إيرادات | مراجعة الترخيص |

## شروط أي مزود قبل الاعتماد
- يُنتج GLB قابلًا للتنزيل (وليس صورة مولَّدة فقط).
- سياسة حذف/احتفاظ موثقة للصور.
- ترخيص يسمح باستخدام المخرجات في الألعاب.
- سقف تكلفة معروف، وبديل عند التوقف أو تغيّر السعر.
